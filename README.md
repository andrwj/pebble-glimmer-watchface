# Glimmer for Pebble

</p>

Glimmer is a dynamic analog watchface tailored for Pebble smartwatches, featuring smooth catch-up rolling animations, natural wrist gestures, and an ultra-low-power hybrid architecture.

---

## ✨ Features

- **Catch-up Rolling Animation**: Smoothly catches up to the current time with an easing animation when waking from standby.
- **Natural Wrist Gestures**: Put the watch to sleep by turning it outward, and wake it up instantly by turning it back or tapping the screen.
- **Ultra-Low Power Architecture**: Minimizes screen redraws and maximizes deep sleep efficiency while preserving full analog aesthetics.
- **Clean Typography**: High-contrast Day and Date display positioned under the hands for maximum legibility.
- **Customizable Settings**: Configure gesture sensitivity, display colors, and update intervals via the mobile settings page.
